# 模板适配与协作演示

## 对比结论

| 项目 | 实际职责 | 本系统借鉴方式 |
| --- | --- | --- |
| [lark-slides](https://github.com/larksuite/cli/blob/main/skills/lark-slides/SKILL.md) | 导入PPTX、读取原生页面结构，再修改、回读及检查 | 先盘点真实对象与版式，再改写指定文本槽；保留未修改对象 |
| [gws-slides](https://github.com/googleworkspace/cli/blob/main/skills/gws-slides/SKILL.md) | Google Slides的创建、读取与批量更新API入口 | 将本地制作和云端演示分开，云端连接按需启用 |
| [recipe-create-presentation](https://github.com/googleworkspace/cli/blob/main/skills/recipe-create-presentation/SKILL.md) | 创建演示、取得编号及配置分享的示例流程 | 为制作结果增加协作入口；不把创建空文件当成已完成设计 |

上述内容是源码与文档对比，未进行三个项目的同题视觉排名。它们不能直接保证任意模板的中文都恰好放入文本框。用户的源配色、源字号、指定字体及事实要求优先，不引入外部默认商务配色。

## 新模板的制作流程

1. 在“版式与Skills”上传PPTX，绑定可编辑底稿和用户提示词。
2. 读取母版、布局继承、空白占位符、表格单元格、字号、内边距及原生对象。几何容量是估算，不能替代Office实测。
3. 模型分批阅读每一页，建立用途、模块关系及文本槽职责。能生成预览时同时传入图片；只有实际收到原生视觉读取确认的页面才标记视觉已读。无图片或不支持视觉时记录为结构分析。
4. 选择模板用途：“底稿模板”允许重复正文容器；“完整参考稿”每个参考页最多一次。普通素材仍遵守整稿不重复规则。六页以内默认视为底稿，这是可人工调整的初始判断。
5. 按文档、页数、模块数量和每个槽的容量规划，再逐页并行写作。页数自动规划不固定12页，不把第11页固定为说明。
6. 每个模块的标题、正文和本页主题必须关联。短标签不承载长句，空白占位符也不能遗漏。模板示例事实不得带入。
7. 写回原生对象，保留源色与源字号。先进行结构和容量校验，导出时执行现有原生文字实测；失败只修受影响页面，保持已通过页。
8. 生成预览供逐页检查。实际不适配时换版或重新分配内容，不用持续缩小字号解决。

[飞书模板工作流](https://github.com/larksuite/cli/blob/main/skills/lark-slides/references/workflow/template-editing.md)采用导入原稿后编辑的方式；[Google模板合并指南](https://developers.google.com/workspace/slides/api/guides/merge)使用复制模板并替换占位文字。本项目保留本地PPTX作为源文件，不依赖先转换到第三方格式。

## 从素材库生成可复用模板

“沿用当前底稿”使用已上传的机构PPT，提供Logo、页眉及基础画布。它本身不会根据需求设计新模板。

在“版式与Skills”点击“AI生成模板”，填写用途、所需版式及汇报对象，选择机构底稿和可选素材套系。可以生成4–12个版式，包含封面、目录、正文与结束页。例：工作汇报，包含三项工作并列、流程路径、成果对比及照片展示。

机构底稿选择“从素材库设计整套模板”时，封面也从素材库选取，普通标题色取自所选素材的实际配色。没有上传底稿时也可使用这种方式；不会临时绘制一套与素材无关的图案。需要沿用企业Logo和页眉时选择原有机构底稿。

Hermes先按需求规划，再从真实可编辑素材中选择组合。除机构底稿页面外，一套模板从同一素材来源选取，保留原色；不同版式不重复使用同一源页。正文组件按安全区域放置或安全重排；主体过窄、过矮时退回重新选版。源字号保留，统一使用微软雅黑。

每页写作代理读取真实对象、空白占位符、原字号容量，以及存在时的源页预览。模板使用通用占位提示和模块职责，不把素材的示例业绩当作新文档事实。写作最多三页并行；失败后保留已完成页，可从断点继续。未来使用模板时，根据保存的模块职责和真实槽位重新组织文案。

生成后在弹窗查看全页预览与选用理由，可下载原生PPTX。点击“保存为可复用模板”后进入自己的版式列表；普通用户只能访问自己的模板任务，不能因此浏览完整素材库。没有通过Office文字检查或全页预览不完整时只能先保存草稿，不能直接用于生成。

这是对已有原生素材的选版与重组，不是随机绘制新图案。图片仍保留图片本身的编辑能力；复杂数据对象走已有图表绑定流程，不作为普通图解混入模板。检查通过也不等于任意长文都能放入，后续仍按槽位容量改写或换版。

## 主题初稿

创作工作台切换“主题初稿”，输入主题与方向。主题和长文档分别保存输入，不会用旧文档冒充新主题。生成结果记录`sourceProvenance.kind=topic-draft`与待核实状态。可以提出框架和行动建议，不编造已经发生的业绩、统计数字、人员或来源。正式汇报前补充并核查事实。

## 系统内协作

打开已生成作品 → “协作与演示” → 输入已注册账号，选择查看或编辑权限。复制`/slides/<随机编号>`链接，对方登录后才能打开；链接本身不授予权限。

- 查看者：查看页面预览、按页评论、跟随汇报或自行浏览；无源文档、讲者备注和编辑接口权限。
- 编辑者：进入已有逐页工作台，通过Hermes修改原生文字、素材、图案与布局。共享作品不授予批量删除和永久删除权限。
- 拥有者：管理成员、撤回权限、创建外部副本。
- 远程汇报：一名编辑者开始同步演示后，其他人自动跟随翻页；支持暂停跟随、恢复跟随、键盘和全屏。采用SSE同步，网络恢复后重新取得快照。
- 并发修改沿用作品锁和版本冲突校验；不是多人同时输入同一个文本框的字符级协作。没有内置音视频会议。

最近作品的“协作演示”可打开自己创建或受邀加入的房间。仅有局域网地址时，同网用户可访问；跨公网汇报需要另外部署可访问的HTTPS地址与网络入口。

## 可选飞书 / Google 连接

“协作与演示”内展开云端发送，输入目标平台的访问令牌，主动发送当前版本的副本。令牌只存在组件内存与本次请求，不保存至账号、浏览器存储或协作记录。局域网HTTP部署请仅在可信网络使用；公开部署需HTTPS。

- Google：通过[Drive原生格式转换上传](https://developers.google.com/workspace/drive/api/guides/manage-uploads#import_to_google_docs_types)创建Google Slides副本。需要OAuth access token及Drive写入权限；未实现一键OAuth登录及自动续期。
- 飞书/Lark：按官方CLI的[导入接口流程](https://github.com/larksuite/cli/blob/main/shortcuts/drive/drive_import.go)上传并创建Slides导入任务；待完成时返回ticket，可继续查询，不重复上传。当前单文件上限20MB，更大文件下载后手动导入。
- 不自动邀请外部人员，不设置公开分享，不双向覆盖本地文件。云端转换可能改变字体、动画或复杂对象，需要再次检查。

连接器有模拟协议测试；没有配置真实外部账号时，不能声称已经完成真实云端授权、转换和双向同步。
## 停止与续作

创作工作台的进度卡提供“停止生成”，单页对话运行时发送按钮切换为停止按钮，AI模板窗口和Hermes任务详情也提供停止入口。只有任务发起者或管理员可以停止任务；协作编辑权限不包含停止其他用户的任务。

停止会取消当前任务的Hermes进程，停止调度后续页面，保存已接受的页面、文案和照片。正在进行的Office检查或渲染先到达安全结束点，界面在此期间显示“正在停止”；不会关闭用户自己打开的PowerPoint。任务停止后不发布本次未完成版本。进入最终保存后无法中断，等待保存完成即可。

整稿与AI模板可从断点继续；单页对话可点“重新编辑这次要求”恢复文字及照片再发送。停止不等于失败，不自动重试和消耗模型额度。已完成稿不因停止而被覆盖。

## 溢出与生成模板兜底

系统先依据Office实测结果修复文案和安全文本框尺寸，保持素材原字号。再次溢出则寻找适配的新版式；没有候选时，Hermes从原配色套系选择真实的可编辑模块，按本页内容数量重组一页模板，再填写全部内容并重新验收。生成模板只关联当前作品，不自动进入全局素材库。封面、完整结束页、统计图及严格原生参考版式保留各自专用流程。

生成模板也必须通过正文占比、对象完整性、主题关联和原字号文字检查。若素材库缺少可复用组件或新页仍未通过，保留断点并报告原因，不强行导出问题页面。每轮修复次数有界，避免反复调用模型。素材原页的报告标题有明确前缀、与目录标题相符且处于页眉区域时，作为页眉装饰移除，不作为正文标签填充。
