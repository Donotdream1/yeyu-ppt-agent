# 并行页面工作流

仅适用于协调器已指定角色的批量制作。单页换版、仅看方案或风格识别遵循其原有受限任务。

叙事规划智能体读取原文及用户规范，判断用途和素材配色，提交整套逐页主题、要点、逻辑关系与必要图表依据。提交大纲后停止，后续流程由程序协调，不在同一段会话中逐页制作整套PPT。

素材协调器使用原生对象解析与有界缓存，对每页匹配候选，检查源对象完整保留、主体占比和槽位容量。一般素材面积占比至少0.45；BNA内容页正文的宽、高利用率分别至少0.90；目录允许居中留白，宽度至少0.90、高度至少0.45，不合格时重排或换材。跨组件关系不安全时不能强行拆分。BNA模板首页直接填原生封面，不检索额外封面素材、不为它编造槽位。

视觉选版角色在写作前比较每页最多四个候选缩略图。真实图片通过用户指定DeepSeek官方接口接受后，记录image-understanding；图片缺失或不支持图像时记录geometry-only。优先同套素材，依据图形关系、阅读顺序、信息密度、原字号容量选择，输出具体来源页与copyGuidance；不从图片旧例句提取新业务事实。写作角色只使用原文units，并以源字号为起点填写；明显失衡时通过显式style调整可读字号，不自动缩字。

页面写作及修改采用一页一个Hermes实例，默认最多4页并行，可配置1–6页；每个实例只接收自己一页的units、原文证据、slots、局部错误与共享designLock。工具页码枚举限定为该页，运行时再次校验，不允许提交相邻页。已知工具直接提供，不先查询工具说明。通过ppt_commit_pages提交非固定内容，contentIds属于本页，数字、单位、限定保留；固定编号由程序处理。不得修改其他页、重建大纲或发布整稿。图表文字修复同样逐页并行，数据与单位保持。

校验错误以具体页、slot、缺失要点与字符容量返回。局部修正已合并的稿件，不重传其他通过页；两次相同失败应结束该页实例并保存真实状态，其他页继续运行，避免反复提交相同内容耗尽全稿轮次。原文不足以支撑素材时明确提出换材，不能用空话或虚构事实填满。

科研模式提交ppt_research_pages，依据科研参考规范填写结构和逐字证据，不进入旧的整页素材文字槽流程。图表规格由图表技能与原文核验，禁止把源素材示例当成真实数据。

协调器在每次有效提交后原子保存页面快照。中断后读取已通过页面、原生素材版本和模板参数，复用已完成稿件，只调度未完成或未通过检查页。API Key不落盘，恢复时使用运行环境或用户重新提供的凭据。

全稿只汇总检查一次；Office组合、文字实测和预览通过串行队列执行。导出发现文字溢出时，返回受影响页面给写作角色局部精简，其他页面保持。完整通过后才发布文件，不把填充页数或模型自述当成已交付PPT。
