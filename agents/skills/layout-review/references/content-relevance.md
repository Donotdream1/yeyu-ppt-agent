# 页面主题与模块内容关联

在内容填充后、原生导出前执行 `ppt_review_content`。只检查已生成的可见内容，不把素材示例作为原文证据。

逐模块判断：标题是否概括正文；正文是否支撑页面主题；同层模块是否按同一种逻辑组织；是否因槽位过多而重复填充。合理缩写、语义归纳、摘要与数字徽标之间的重复、用户要求的照片占位均可保留，不以关键词字面重合代替语义判断。

结果分为 pass、rewrite、replace-material。rewrite指出具体slot和关联薄弱的原因，局部改写标题或正文；replace-material说明结构或模块数如何不适配，重新检索、视觉选版与填充。禁止编造更强结论来提高所谓关联度。改写后重新检查，连续两次仍不通过则保存断点和实际问题，不能假装通过或无限重试。

通过记录绑定主题、正文、素材与审校版本的签名。未改变的页复用已通过记录；内容或素材变化时重新检查。最多四页一批、两批并行，审校意见与工具事件可在Hermes过程页查看。
