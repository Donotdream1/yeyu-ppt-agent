# GitHub技能适配：PM Meeting Notes

来源：shangbianai/pm-meeting-notes，提交198052ce157fff377c5fd7423e700103a7a84a4b，SKILL.md，MIT，DPXJ。原文及许可证见agents/vendor/office-skills/meeting。

采用的方法：把口语转写整理为讨论、决定、风险、行动项和待确认问题；严格区分转写原文、归纳和分析推断；保留原文信号，不编造负责人、日期或决策。

本地变更：音频识别工具负责录音转文本，Hermes负责纪要与指令理解。禁用固定菜单和单独HTML应用生成，改为本系统的纪要编辑、Word导出及任务确认；没有实际说话人分离功能就不宣称已分离。
